# Observability Stack – Cost & Reliability Signal Integration-------------------------------

A centralized monitoring and observability platform built using Prometheus, Grafana, Loki, CloudWatch, SNS, and ELK.

## Overview------------------------------------------------

This project provides real-time infrastructure monitoring, log aggregation, alerting, and reliability insights for cloud workloads.

The solution combines metrics, logs, and alerts into a single observability platform.

## Technologies----------------------------------------------------

* Prometheus
* Grafana
* Loki
* CloudWatch
* SNS
* ELK Stack
* AWS

## Features-----------------------------------------------------------

* Infrastructure Monitoring
* Centralized Logging
* Alert Management
* Resource Utilization Tracking
* Cost Visibility
* Reliability Monitoring

## Architecture--------------------------------------------------------

Prometheus → Grafana

Loki → Grafana

CloudWatch → SNS Alerts

ELK → Log Analytics
